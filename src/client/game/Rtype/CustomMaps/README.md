# CustomMaps

Put your maps here, as `.json` files. In the lobby of the game, press **Tab**
to open the **Custom map** tab: your maps are listed there.

- `simple.json`: the smallest useful map, to start from.
- `example.json`: a longer map that uses every kind of element.

The full guide, with every field, is in the documentation: `docs/custom-maps.md`.
